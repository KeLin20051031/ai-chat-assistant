# AI智能助手

一个基于 Web 的 AI 智能助手应用，支持文件上传、对话管理等功能。

## 🌐 在线访问

👉 **[点击访问网站](https://KeLin20051031.github.io/ai-chat-assistant)**

## ✨ 功能特性

- 🤖 AI 智能对话
- 📁 文件上传与管理（支持 PDF、Word、图片等）
- 💾 本地存储
- 📱 响应式设计

## 🛠️ 技术栈

- HTML5
- Tailwind CSS
- JavaScript
- Marked.js（Markdown 渲染）

## 📁 项目结构

```
├── index.html          # 网站入口（自动跳转）
├── ai-chat-app.html    # 主应用文件
├── README.md           # 项目说明
└── .gitignore         # Git 忽略配置
```

## 🚀 本地使用

直接在浏览器中打开 `ai-chat-app.html` 或 `index.html` 文件即可使用。
